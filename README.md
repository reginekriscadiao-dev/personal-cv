A responsive personal CV webpage with a soft lavender and purple design, profile section, education timeline, creative toolkit, and GitHub contact link.

## Open the webpage

Open `index.html` in any modern browser. No installation, build step, or internet connection is required for the page itself. Open this project folder in Visual Studio Code to edit it.

## Add your own photo

1. Copy your portrait into the `assets` folder and name it `profile.jpg`.
2. In `index.html`, change `src="assets/profile.svg"` to `src="assets/profile.jpg"`.
3. Change that image's `alt` text to `Portrait of Regine Kris Cadiao`.
4. Save and refresh your browser. A vertical portrait works best; CSS crops it to fit.

The included illustration is a placeholder, not a photograph of Regine.

## Understand the code

- `index.html` defines the content. The `header`, `nav`, `main`, `section`, and `footer` tags organize the page semantically.
- Links such as `href="#education"` scroll to the section with the matching `id`.
- `styles.css` defines colors, spacing, typography, and layout. Variables in `:root` control the main theme.
- CSS Grid arranges the main columns; Flexbox aligns navigation, buttons, and cards.
- Media queries at the bottom of the stylesheet stack the content on smaller screens.
- `assets/profile.svg` is the replaceable portrait illustration.
- No JavaScript or external frameworks are needed.
